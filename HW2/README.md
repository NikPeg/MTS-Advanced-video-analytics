# Домашнее задание 5: Временная стабилизация масок (Anti-Flicker)

## Описание

Реализация системы временной стабилизации масок для видео-сегментации (**Вариант A**).

Проект демонстрирует проблему мерцания масок при покадровой сегментации и сравнивает три метода временного сглаживания для устранения этого эффекта.

## Пайплайн

### 1. Загрузка данных
- Видео: `tall.mp4` (100 кадров для ускорения обработки)
- Разрешение сохранено оригинальное

### 2. Модель сегментации
- **Модель**: DeepLabV3 с ResNet-50 backbone
- **Предобучение**: ImageNet + COCO
- **Целевой класс**: person (класс 15 в COCO)
- **Выход**: Вероятностные маски (значения от 0 до 1)

### 3. Метрики нестабильности

Для оценки качества временной стабильности используются три метрики:

1. **IoU между соседними кадрами**
   - Intersection over Union для бинаризованных масок
   - Показывает согласованность масок во времени
   - Чем выше → лучше стабильность

2. **Temporal Variance**
   - Среднее абсолютное изменение вероятностей маски
   - Измеряет величину изменений между кадрами
   - Чем ниже → меньше мерцания

3. **Boundary Flickering**
   - Изменение контуров маски между кадрами
   - Фокусируется на стабильности границ
   - Чем ниже → стабильнее границы

### 4. Методы сглаживания

#### a) Temporal Averaging (Усреднение по окну)
```python
smoothed_mask[t] = mean(masks[t-w:t+w+1])
```
- **Параметр**: window_size = 5
- **Преимущества**: Простой, быстрый, эффективен против шума
- **Недостатки**: Размывает границы при быстром движении

#### b) Median Filtering (Медианная фильтрация)
```python
smoothed_mask[t] = median(masks[t-w:t+w+1])
```
- **Параметр**: window_size = 5
- **Преимущества**: Устойчив к выбросам, сохраняет границы
- **Недостатки**: Вычислительно затратный

#### c) Exponential Smoothing (Экспоненциальное сглаживание)
```python
smoothed_mask[t] = α * mask[t] + (1-α) * smoothed_mask[t-1]
```
- **Параметр**: α = 0.3
- **Преимущества**: 
  - ✓ Лучший баланс стабильность/отзывчивость
  - ✓ Адаптивная реакция на изменения
  - ✓ Минимальная задержка (только прошлые кадры)
  - ✓ Один параметр для настройки
- **Рекомендация**: **Лучший метод для практического применения**

## Инженерный вывод

### Когда сглаживание помогает:
- ✓ Медленно движущиеся или статичные объекты
- ✓ Стабильные условия освещения
- ✓ Высокая частота кадров (30+ FPS)
- ✓ Небольшие колебания границ маски

### Когда сглаживание ухудшает результаты:
- ✗ Быстрые движения и резкие повороты
- ✗ Окклюзии (объект частично скрывается)
- ✗ Появление/исчезновение объектов
- ✗ Низкая частота кадров (<15 FPS)

### Рекомендации для продакшена:

1. **Baseline метод**: Exponential Smoothing с α=0.3
2. **Адаптивный подход**: Изменять α в зависимости от величины оптического потока
3. **Детекция окклюзий**: Комбинировать с детектором для предотвращения drift
4. **Для критичных случаев**: Рассмотреть STM, XMem или другие VOS-модели с памятью

## Ключевые параметры

### Чувствительные параметры:

1. **Размер окна** (для averaging/median): 
   - 3-7 кадров оптимально
   - Больше → больше сглаживание, но медленнее реакция

2. **Alpha** (для exponential):
   - 0.2-0.4 → стабильные маски, медленная реакция
   - 0.5-0.7 → быстрая реакция, меньше сглаживания
   - **Рекомендация**: 0.3 как универсальное значение
