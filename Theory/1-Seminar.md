## Семинар 1. Инструментарий работы с видео: PyAV, FFmpeg, Optical Flow

### Цель семинара

Научиться работать с видео как с дискретным сигналом: читать, декодировать, анализировать временные метки, корректно извлекать кадры при CFR и VFR, использовать аппаратное ускорение и проводить простейший анализ качества и движения. Семинар формирует инженерную базу, без которой невозможна надёжная видеоаналитика.

---

### **Задание 1. Проверка временной структуры и CFR/VFR**

1. Выберите два ролика: один с постоянной частотой кадров (CFR), другой с переменной (VFR).
2. Определите параметры потока с помощью FFmpeg:

   ```bash
   ffprobe -show_streams -select_streams v:0 video.mp4
   ```

   Сравните `avg_frame_rate`, `r_frame_rate`, `time_base`.
3. Постройте график интервалов между соседними кадрами по PTS. Для VFR кадры будут распределены неравномерно.
4. Ответьте: как изменяется реальное время видео при наличии variable frame rate и почему это важно для обучения моделей?

2. Для теста используйте VFR-видео и сравните временные позиции извлечённых кадров с ожидаемыми равномерными интервалами.
3. Добавьте параметр `mode=('uniform'|'random')` — для выбора между равномерным и случайным сэмплингом.
4. Проверьте совпадение длительности видео и таймингов ваших кадров (с погрешностью < 1%).

### **Задание 3. Аппаратное и программное декодирование**

1. Установите FFmpeg с поддержкой NVDEC или VAAPI.
2. Сравните скорость декодирования на CPU и GPU:

   ```bash
   ffmpeg -benchmark -i video.mp4 -f null -    # CPU
   ffmpeg -hwaccel cuda -benchmark -i video.mp4 -f null -   # GPU
   ```
3. Проанализируйте лог: измерьте среднее время на кадр и общую пропускную способность.
4. Оцените разницу в latency и энергопотреблении. Объясните, когда выгодно использовать аппаратное декодирование в пайплайнах компьютерного зрения.

### **Задание 4. Мини-анализ качества видео**

1. С помощью FFmpeg сравните исходное и перекодированное видео при разных CRF:

   ```bash
   ffmpeg -i input.mp4 -c:v libx264 -crf 18 out18.mp4  
   ffmpeg -i input.mp4 -c:v libx264 -crf 28 out28.mp4  
   ```
2. Для каждой пары вычислите PSNR и SSIM:

   ```bash
   ffmpeg -i input.mp4 -i out28.mp4 -lavfi psnr="stats_file=psnr.log" -f null -  
   ffmpeg -i input.mp4 -i out28.mp4 -lavfi ssim="stats_file=ssim.log" -f null -
   ```
3. Постройте зависимость PSNR от CRF.
4. Объясните, почему субъективное восприятие качества не всегда соответствует PSNR и почему для оценки видеоаналитики важнее стабильность цветового и временного сигнала, чем высокая визуальная чёткость.

### **Задание 5. Optical Flow и движение между кадрами**

1. Реализуйте простую оценку движения между соседними кадрами с помощью OpenCV:

   ```python
   import cv2, numpy as np
   prev = None
   for frame in frames:
       gray = cv2.cvtColor(frame, cv2.COLOR_RGB2GRAY)
       if prev is not None:
           flow = cv2.calcOpticalFlowFarneback(prev, gray, None, 0.5, 3, 15, 3, 5, 1.2, 0)
           mag, ang = cv2.cartToPolar(flow[...,0], flow[...,1])
           print(f"Mean motion magnitude: {mag.mean():.3f}")
       prev = gray
   ```
2. Найдите кадры с наибольшей интенсивностью движения.
3. Объясните, как aliasing по времени и длинная экспозиция влияют на расчёт оптического потока.
