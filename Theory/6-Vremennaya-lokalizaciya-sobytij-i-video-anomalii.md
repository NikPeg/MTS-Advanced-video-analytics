# Временная локализация событий и видео-аномалии

## Переход от статических изображений к видеопотокам

Видеопоток — это дискретизация непрерывной функции V(t) : ℝ → ℝH×W×C, где каждый момент связан с соседними физически и семантически.

### Кадровый подход
Независимые изображения, пространственные операции.

### Временной подход
Непрерывный сигнал, динамика и эволюция признаков.

### Ключевое отличие
События не локализуются в одном кадре.

## Природа событий в видео

Событие — непрерывный фрагмент времени с семантическим содержанием:

```
e = [t_start, t_end] ⊆ ℝ
```

### Латентная природа
События имеют размытые границы и постепенные переходы между состояниями.

### Неопределённость границ
Вынужденная аннотация конечными точками времени создаёт фундаментальную неопределённость.

## Распознавание vs Локализация

### Распознавание действий
Классификация клипа фиксированной длины:

```
f : {V(tk)}T_k=1 → c
```

Границы заданы априори.

### Временная локализация
Предсказание классов и границ:

```
f : {V(tk)}N_k=1 → {(ci, [t_start, t_end])}M_i=1
```

Границы — латентные переменные.

## Три уровня представления

### Покадровое
Вектор признаков для каждого кадра: sk = g(V(tk)). Игнорирует длительность состояний.

### Клиповое
Агрегация соседних кадров: ci = h({V(tk)}i+T_k=i). Фиксированная длина окна.

### Событийное
Интервалы с семантическим смыслом. Переменная длительность, возможны перекрытия.

## Полная и слабая разметка

### Полная разметка
Точные временные границы для каждого события.

### Слабая разметка
Только классы событий без границ.

Прямая регрессия границ имеет высокую стоимость аннотации и субъективные решения экспертов.

Границы — скрытые переменные, требуют специальных архитектур, более реалистична для практики.

## Неопределённость границ

Истинные границы событий — случайные величины:

```
t_start, t_end ~ p(t | V)
```

### Природа проблемы
Начало и конец событий размыты во времени, зависят от контекста.

### Практические проявления
Низкая согласованность между аннотаторами, разброс в десятки кадров.

### Инженерное решение
Допуски по времени, IoU интервалов, вероятностные представления.

## Формализация задачи локализации

Дана временная последовательность признаков X = (xt)T_t=1. Требуется найти набор интервалов:

```
E = {(ci, [si, ei])}M_i=1
```

максимизирующий апостериорную вероятность: p(E | X)

Ключевые аспекты: число событий M неизвестно, интервалы могут перекрываться, задача является структурным предсказанием.

## Типовые ошибки постановки

- **Редукция к покадровой классификации** — пороговое выделение интервалов без учёта длительности приводит к фрагментации
- **Фиксированные окна** — игнорирование вариативности длительности событий вызывает систематические смещения
- **Недооценка постобработки** — без явного сглаживания нейросеть не выдаёт чистые интервалы

## Связь с временной когерентностью

Временная локализация — логическое продолжение идей когерентности, перенесённое с уровня пикселей на уровень событий.

- **Сегментация** — согласованность масок между кадрами
- **Локализация** — согласованность оценок активности во времени

Общий фундамент: фильтрация шума и учёт временной структуры сигнала.

## Скользящее окно

Простейший метод добавления временного контекста:

```
Xi = {xi, xi+1, ..., xi+T-1}, si = f(Xi)
```

### Преимущества
- Интуитивная простота
- Использование готовых моделей
- Параллельная обработка

### Фундаментальные ограничения
- Фиксированная длина окна
- Дрожание предсказаний
- Разрыв длинных событий

## Временная агрегация признаков

### Простое pooling
Усреднение по времени и пространству: z = Pool(z1, z2, ..., zI)

- **Среднее pooling** — усреднение по времени, теряет динамику
- **Максимальное pooling** — выделяет пики активности
- **Temporal attention** — взвешенная агрегация: αt = exp(v^T zt) / Σk exp(v^T zk)

Ограничение: сложность при больших разрешениях и временных окнах.

## Temporal Convolutional Networks

Прямое обобщение одномерных свёрток на временные последовательности:

```
yt = Σi=0^(K-1) ki × xt-i
```

### Преимущества
- Параллельная обработка
- Фиксированное рецептивное поле
- Детерминированность выходов

### Недостатки
- Локальные временные зависимости
- Устойчивые шаблоны активности
- Временные головы над бэкбонами

## Дилатированные свёртки

Разреженность во временном измерении для увеличения рецептивного поля:

```
yt = Σi=0^(K-1) ki × xt-d×i
```

Коэффициент дилатации d определяет шаг перепрыгивания.

Стек слоёв с возрастающими дилатациями обеспечивает экспоненциальный рост рецептивного поля и объединение локальных и длительных зависимостей.

## Рекуррентные подходы: LSTM

Моделирование через скрытое состояние: ht = f(xt, ht-1)

Механизмы LSTM:
- it = σ(Wi xt + Ui ht-1) — input gate
- ft = σ(Wf xt + Uf ht-1) — forget gate
- ot = σ(Wo xt + Uo ht-1) — output gate
- ct = ft ⊙ ct-1 + it ⊙ tanh(Wc xt + Uc ht-1) — cell state
- ht = ot ⊙ tanh(ct) — hidden state

**ConvLSTM:** замена линейных преобразований на свёртки для сохранения пространственной структуры.

## Трансформеры и временная обработка

Self-attention заменяет рекуррентную обработку:

```
Attn(Q, K, V) = softmax(QK^T / √d) V
```

### Преимущества
- Прямое взаимодействие любых моментов времени
- Нет фиксированного рецептивного поля

### Ограничения
- Квадратичная сложность по длине последовательности T

### Решения
Иерархические схемы, разреженное внимание, window-based attention.

## Self-attention как механизм выделения событий

Матрица внимания отражает связи между кадрами:

```
A_ij = (q_i^T k_j) / √d
```

- **Внутри события** — высокие веса, большие значения A_ij
- **Между событиями** — низкие веса, малые значения

Начало и конец событий определяются через пороговое внимание.

## Ограничения по длине последовательности

Для видео длиной 90K кадров при 25 FPS требуется обработка ~25 секунд.

O(T²) сложность self-attention в полной последовательности.

Решение: иерархические схемы, разреженная агрегация, оконные подходы.

## TCN vs Трансформеры

### Temporal Convolutional Networks
- Простота и стабильность
- Контроль латентности
- Локальная обработка
- Детерминированность

### Трансформеры
- Высокая выразительность
- Глобальный контекст
- Гибкость зависимостей
- Вычислительная сложность

Гибридный подход: TCN для локальной обработки + трансформер для глобальной агрегации.

## Инженерная интеграция

Видеобэкбон извлекает пространственные визуальные признаки из кадров.

Временная голова — TCN / LSTM / Трансформер для моделирования динамики.

Выходной слой — оценки активности и границ событий.

## Необратимое решение

Видеопоток проходит через бэкбон: V(t) → X = {x1, x2, ..., xT}, xt ∈ ℝd

Необратимое решение — пространственная структура схлопывается в компактный эмбеддинг.

Параметры задачи — stride по времени и длина клипа определяют возможность восстановления границ.

Если событие не оставило след в признаках, оно не может быть восстановлено позже.

## От сигнала к временной модели

Временная модель формирует оценки:

```
st = f_temp(xt)
```

где st — дискретная аппроксимация латентной непрерывной функции активности a(t) ∈ [0, 1].

Критическая ошибка: рассматривать {st} как независимые вероятности. В действительности это временной сигнал с корреляцией, инерцией и шумом.

Выход временной модели — сырьё для дальнейших преобразований, а не финальный ответ.

## Одностадийная локализация

Прямое предсказание признаков в события:

```
f : {xt}T_t=1 → {(ci, ŝi, êi)}M_i=1
```

### Ключевые проблемы
- Множество выходов к разным границам событий, требуется постобработка
- Прямая регрессия границ — высокая дисперсия предсказаний
- Нестабильность — высокая чувствительность к шуму, необратимая потеря информации

## Двухстадийный подход

Генерация кандидатных интервалов с последующей классификацией:

```
P = {[si, ei]}K_i=1
```

1. Формирование множества временных предложений
2. Классификация каждого кандидата
3. Фильтрация и уточнение границ
4. Подавление дубликатов (Temporal NMS)

Преимущество: задача становится отбором структур, а не регрессией.

## Регрессия границ

Предсказание смещений относительно опорных точек:

```
ŝ = t - Δts, ê = t + Δte
```

Ошибка начала влияет на перекрытие интервалов и IoU. Ошибка конца искажает длительность события.

Проблема: сырые предсказания имеют высокую дисперсию, особенно на границах с плавным изменением сигнала.

## Перекрывающиеся события

Реальные видеопотоки содержат интервалы с пересечениями:

```
[si, ei] ∩ [sj, ej] ≠ ∅
```

### Нормальный режим
События часто перекрываются или образуют вложенные структуры.

### Проблема наивных подходов
Пороговое выделение не различает перекрытия.

### Решение
Многоканальные представления или независимые потоки предложений.

## Temporal NMS

Подавление дубликатов по временному IoU интервалов:

```
IoU = |[s1, e1] ∩ [s2, e2]| / |[s1, e1] ∪ [s2, e2]|
```

### Необходимость
Устранение дублирующих предсказаний.

### Опасность
Жёсткое подавление уничтожает вложенные интервалы и мелкие события.

### Практика
Мягкие варианты подавления, многоуровневая фильтрация.

## От сигнала к интервалам

Весь конвейер как отображение:

```
{st}T_t=1 → {[si, ei]}M_i=1
```

### Недифференцируемость
Включает пороговые операции, объединение сегментов, фильтрацию.

### Индуктированные предположения
Здесь закладывается определение того, что считать событием.

### Ручная настройка
Параметры связаны с FPS, латентностью и требованиями приложения.

## Связь с метриками

Временная локализация — не покадровая задача. Качество оценивается через:

- Совпадение интервалов — степень перекрытия предсказанных и истинных событий
- Устойчивость границ — стабильность предсказаний начала и конца
- Корректность структуры — правильное представление перекрытий и вложенностей

## Метрики в видео-аналитике

Оценка качества временной локализации требует специальных метрик, учитывающих событийную природу задачи.

## Почему покадровая точность неприменима

Объект предсказания — временной интервал, а не момент времени.

Ошибка подхода: покадровая точность оценивает совпадение индикаторных функций 1t∈I_pred и 1t∈I_true.

Что теряется: не различает систематический сдвиг границ, переоценку длительности и фрагментацию.

Последствия: не коррелирует с качеством локализации, непригодна для обучения и валидации.

## Временная IoU

Базовая мера совпадения интервалов:

```
IoU(I1, I2) = max(0, min(e1, e2) - max(s1, s2)) / (max(e1, e2) - min(s1, s2))
```

### Чувствительность
Одновременно учитывает сдвиг начала, сдвиг конца и ошибку длительности.

### Масштабирование
Автоматически ужесточает требования для коротких событий.

### Естественность
Соответствует интуитивному пониманию качества локализации.

## mean Average Precision (mAP)

Интегральная метрика по набору порогов IoU: τ ∈ {0.3, 0.5, 0.7}

1. Для каждого порога τ определяется корректность: IoU(I, I_pred) ≥ τ
2. Построение precision-recall кривой по уверенности предсказаний
3. Вычисление средней точности для данного порога
4. Усреднение по классам и всем значениям τ

## Ошибки границ

Доминирующий источник деградации mAP:

```
εs = s - s_true, εe = e - e_true
```

### Систематический характер
Связаны с архитектурой временной модели и постобработкой.

### Нелинейное влияние
Малые ошибки резко снижают IoU для коротких событий.

Вывод: оптимизация границ — центральная проблема, а не второстепенная задача.

## Видео-аномалии

Предельный случай временной локализации без явного класса события.

### Нормальное поведение
Модель обучается на нормальных данных.

### Функция отклонения
Сигнал d(t) превышает допустимый уровень.

### Интервалы аномалий
Выделение I = [s, e] с высоким отклонением.

Изоморфна задаче локализации событий, но с другим источником сигнала активности.

## Реконструкция и предсказание

### Реконструкция
Ошибка восстановления нормальных признаков: rt = xt - x̂t

### Предсказание
Ошибка предсказания будущего: rt = xt+1 - x̂t+1

Устойчивы к шуму, но чувствительны к всплескам.

В обоих случаях {rt} — временной сигнал, требующий преобразования в интервалы.

## Сглаживание временных сигналов

Свёртка с ядром для снижения шума:

```
s̃t = Σk=-K^K wk st+k
```

±K ±K → ±IoU

### Устойчивость
Снижение дисперсии сигнала.

### Смещение границ
Систематический сдвиг начала и конца.

Компромисс: сглаживание должно рассматриваться как часть модели, параметры подбираются совместно с дискретизацией.

## Пороговые стратегии

Переход от сигнала к интервалам через условие:

```
s̃t ≥ τ
```

### Фиксированный порог
Прост, но нестабилен при изменении условий съёмки и домена.

### Адаптивный порог
Основан на статистике сигнала, повышает устойчивость, усложняет интерпретацию.

Пороговое выделение — дискретизирующая операция, определяющая форму интервалов.

## Инженерная интеграция

Временная локализация в реальных системах работает в условиях:

- **Ограниченная латентность** — онлайн-режим, недоступность будущего, причинные фильтры
- **Неполные данные** — пропуски кадров, VFR, рассинхронизация таймстемпов
- **Нестабильный FPS** — систематический сдвиг границ, невозможность компенсации постфактум

Заключение: архитектурные и метрические решения неотделимы от инженерных ограничений.
