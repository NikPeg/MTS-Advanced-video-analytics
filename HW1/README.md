# Инструкция по проверке выполнения HW1

## Описание

Этот проект реализует все 10 задач семинара №2 "Собираем быстрый пайплайн данных" по построению эффективного видеопайплайна.

## Установка зависимостей

```bash
pip install -r HW1/requirements.txt
```

Или установка вручную:
```bash
pip install torch torchvision av numpy opencv-python matplotlib tensorboard pillow tqdm
```

### Установка decord (опционально, для задачи 7)

**Примечание:** `decord` может быть недоступен через pip на некоторых платформах (особенно macOS). Для задачи 7 (аппаратное декодирование) требуется `decord`. Если его нет, задача будет работать только с PyAV.

**Способы установки decord:**

1. **Через pip (если доступно):**
   ```bash
   pip install decord
   # или конкретная версия
   pip install decord==0.6.0
   ```

2. **Через conda (рекомендуется для macOS/Linux):**
   ```bash
   conda install -c conda-forge decord
   ```

3. **Альтернатива - decord2 (новая версия):**
   ```bash
   pip install decord2
   ```
   *Примечание: если используете decord2, может потребоваться небольшая модификация кода.*

Если `decord` не установлен, задача 7 автоматически будет использовать только PyAV (CPU декодирование).

## Проверка выполнения каждой задачи

### Задача 1: Базовый декодер видеокадров

**Что проверяется:**
- Корректное чтение кадров из видео
- Правильная форма выходного массива (T, H, W, 3)
- Вывод индексов кадров и фактической частоты кадров

**Как проверить:**
```bash
python HW1/video_pipeline.py --video sample_video.mp4 --task 1
```

**Ожидаемый результат:**
- В консоли выводятся индексы прочитанных кадров
- Выводится фактическая частота кадров видео
- Выводится форма массива клипа: `(16, H, W, 3)` для 16 кадров

**Визуальная проверка:**
При запуске с `--all` создается файл `HW1/results/task1_frames.png` с первым и последним кадром клипа.

### Задача 2: Реализация Dataset для видеоклипов

**Что проверяется:**
- Работа класса `VideoDataset` с DataLoader
- Корректная загрузка батчей

**Как проверить:**
Задача 2 проверяется автоматически при выполнении задач 3-9, которые используют `VideoDataset`.

**Ожидаемый результат:**
- DataLoader успешно итерируется по датасету
- Батчи имеют правильную форму: `(batch_size, T, H, W, 3)`

**Критерии успеха:**

### Задача 5: Prefetch и pinned memory

**Что проверяется:**
- Влияние prefetch_factor и pin_memory на FPS и jitter

**Как проверить:**
```bash
python HW1/video_pipeline.py --video sample_video.mp4 --task 5
```

**Ожидаемый результат:**
- В консоли выводится таблица сравнения 4 конфигураций:
  - Baseline (без оптимизаций)
  - Prefetch (prefetch_factor=2)
  - Pinned Memory (pin_memory=True)
  - Both (обе оптимизации)

**Критерии успеха:**
- Prefetch и pinned memory улучшают FPS
- Jitter уменьшается при использовании оптимизаций
- Комбинация обеих оптимизаций дает лучший результат

**Хорошие показатели:**
- Улучшение FPS на 10-30% при включении оптимизаций
- Jitter < 0.1 для стабильного пайплайна

---

### Задача 6: Pipeline overlap

**Что проверяется:**
- Перекрытие декодирования и инференса в разных потоках
- Сравнение latency последовательного и перекрытого выполнения

**Как проверить:**
```bash
python HW1/video_pipeline.py --video sample_video.mp4 --task 6
```

**Ожидаемый результат:**
- Выводятся средние latency для последовательного и перекрытого режимов
- Выводится speedup (ускорение)

**Критерии успеха:**
- Перекрытое выполнение имеет меньшую latency
- Speedup > 1.0 (обычно 1.2-1.5x)

## Возможные проблемы и решения

### Проблема: "decord not available" или "Could not find a version that satisfies the requirement decord"
**Решение:** 
- На macOS/Linux попробуйте установить через conda: `conda install -c conda-forge decord`
- Или используйте альтернативу: `pip install decord2`
- Если не удается установить, задача 7 будет работать только с PyAV (CPU декодирование) - это нормально

### Проблема: "CUDA out of memory"
**Решение:** Уменьшите batch_size в коде или используйте CPU режим

### Проблема: "No frames read from video"
**Решение:** Проверьте путь к видео и формат файла. Убедитесь, что видео содержит достаточно кадров.

### Проблема: Низкий FPS
**Решение:** 
- Увеличьте num_workers
- Используйте GPU если доступна
- Уменьшите разрешение или clip_len
